# NOMA Architecture — Kurumsal Web Sitesi

NOMA Architecture, mimarlık ve tasarım alanında faaliyet gösteren bir stüdyo için tasarlanmış örnek bir kurumsal web sitesi projesidir. Proje, modern web tasarımını işlevsel bir kullanıcı deneyimiyle birleştirerek markanın dijital kimliğini yansıtan bütüncül bir web sitesi oluşturmayı amaçlamaktadır.

## Proje Hakkında

Minimalist tasarım anlayışı, güçlü tipografi, geniş görseller ve sade bir renk paletiyle hazırlanan web sitesi; ziyaretçilere markayı, hizmetleri ve konsept projeleri keşfedebilecekleri düzenli bir deneyim sunar.

Proje kapsamında ana sayfa, hakkımızda, hizmetler, çalışmalarımız, notlar ve iletişim sayfaları geliştirilmiştir. Sayfalar arasında tutarlı bir tasarım dili oluşturulurken farklı ekran boyutlarında kullanılabilirlik de gözetilmiştir.

## Özellikler

- Responsive ve mobil uyumlu tasarım
- Çok sayfalı kurumsal web sitesi yapısı
- Otomatik geçişli ve etkileşimli ana sayfa slider'ı
- Kategori bazlı proje filtreleme
- Kaydırma sırasında devreye giren görünüm animasyonları
- Sürükleme etkileşimi ve dinamik arayüz bileşenleri
- İletişim formu için istemci tarafı doğrulama
- Tutarlı tipografi ve görsel tasarım dili

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.8

## Projenin Amacı

Bu proje, modern ve kullanıcı odaklı bir kurumsal web sitesinin front-end geliştirme sürecini ortaya koymak amacıyla hazırlanmıştır. Tasarım, responsive arayüz geliştirme, sayfalar arası tutarlılık ve JavaScript ile etkileşimli bileşenler oluşturma konularındaki uygulamaları bir araya getirmektedir.

**Not:** NOMA Architecture ve projede yer alan çalışmalar, web tasarımı ve geliştirme amacıyla oluşturulmuş konsept içeriklerdir. İletişim formu sunucu entegrasyonu içermeyen bir arayüz örneğidir.
